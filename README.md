## 🚀 Sobre mí

Soy un desarrollador en formación con enfoque en **Backend**, apasionado por diseñar y construir aplicaciones empresariales robustas. Mi camino en la tecnología comenzó con la curiosidad por entender cómo funcionan los sistemas por dentro, y hoy lo estoy consolidando con una ruta de aprendizaje clara y práctica en el ecosistema **Java**.

Me gusta aprender construyendo: aplico cada concepto nuevo en proyectos reales, cuido la **arquitectura**, la **seguridad** y la **calidad del código**, y trabajo de forma constante para crecer como profesional.

- 🎯 **Enfoque actual:** desarrollo Backend con Java y Spring Boot
- 🧱 **Mis prioridades:** código limpio, APIs REST bien diseñadas, bases de datos eficientes y seguridad
- 🌱 **Aprendiendo:** arquitectura de software, buenas prácticas, testing y despliegue
- 🤝 **Abierto a:** colaboraciones, feedback y oportunidades de crecimiento
